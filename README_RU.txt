MATRIX SPECTRUM v10 — УСТАНОВКА И ОТКАТ
========================================

Архив содержит готовый статический проект GitHub Pages.
После распаковки файлы лежат в корне папки, без вложенных каталогов:
 index.html             — визуализатор и обработка аудио
 manifest.webmanifest   — установка как приложения
 sw.js                  — офлайн-кэш с версией v10
 icon.png, icon-512.png — иконки, сохранены из старой версии
 README_RU.txt          — эта памятка (можно тоже загрузить в репозиторий)

ОБНОВЛЕНИЕ
1. Сначала сохрани ПОЛНУЮ копию старых файлов GitHub Pages на компьютер
   (минимум index.html, sw.js, manifest.webmanifest, обе иконки).
2. Распакуй этот ZIP и скопируй ВСЕ файлы в КОРЕНЬ того же репозитория
   GitHub Pages, заменив одноимённые файлы. Не клади папку v10 внутрь репозитория.
3. Дождись публикации GitHub Pages, обнови страницу.
4. Если KioskHQ показывает старую версию, закрой страницу и очисти КЕШ
   KioskHQ в настройках Android (не обязательно очищать данные приложения).

ОТКАТ НА v9
Загрузи прежние файлы из сохранённой папки на тот же путь в GitHub
(заменяя одноимённые файлы), дождись публикации и очисти кэш KioskHQ.
При откате можно оставить дополнительные файлы, если их не было в v9.

РАБОТА С МИКРОФОНОМ
Нажми «Микрофон», разреши доступ к нему. Для записи нужен HTTPS.
В панели появится диагностика реальных настроек EC / NS / AGC, насколько
их сообщает браузер. 'не указано' означает, что браузер не предоставил флаг.

КАЛИБРОВКА (НЕОБЯЗАТЕЛЬНА)
При включённом микрофоне и выключенном демо нажми «Калибровка тишины».
Обеспечь 3 секунды тишины в помещении, компьютер и вентилятор могут
продолжать работать как обычно. Профиль сохранится в localStorage данного
браузера и будет использован при последующих запусках.
Если изменились комната/место/микрофон, нажми «Сброс профиля» или
сделай калибровку заново. При очистке ДАННЫХ приложения профиль исчезнет.

ЧТО ИЗМЕНИЛОСЬ ПО СРАВНЕНИЮ С v9
- Измерение суммы взвешенных мощностей FFT вместо максимума dB в полосе.
- Перекрывающиеся фильтры с компенсацией слишком узких басовых полос.
- Отдельное отслеживание шумового пола; длительная нота больше не гасится
  вычитанием своего собственного среднего уровня.
- Плавный переход от басовых коэффициентов к средним, без шва на ~209 Гц.
- Один аудиозамер за кадр вместо повторных обновлений фильтров.
- Цифры предварительно собираются в слой один раз на строку, чтобы
  снизить нагрузку на отрисовку без изменения их цвета и свечения.
- Обновлён SW-кэш для более надёжной замены старых версий через GitHub.

НЕ ИЗМЕНЕНО
Оформление v9: фон, палитра и кэшированные глифы, свечение,
скорость 64 мс/строка; диапазон 40–12000 Гц и формула ширины W/88.
Нет A/B-переключателей, двух анализаторов или программного AGC.

ОГРАНИЧЕНИЯ И ПРОВЕРКА
Это первая реализация нового аудиоалгоритма. Его пороги оценены
предварительно, а не откалиброваны на реальном Redmi Pad 2. Громкость
и чистота картинки могут заметно отличаться от v9: проверь тишину,
речь, долгую ноту и музыку на неизменной громкости. Не все гармоники
голоса должны сливаться в одну полосу: часть из них реальна.
Встроенный деморежим синтетический и не проверяет микрофон.
