Matrix Spectrum + Spectral Flow v4 — Studio Edition

УСТАНОВКА: распакуйте архив и загрузите файлы в корень GitHub Pages репозитория. При необходимости обновите страницу или очистите только кеш файлов KioskHQ.

РЕЖИМЫ: «Матрица» (v9.2 по умолчанию) и «Spectral Flow». Кнопка «⚙ Настройки» открывает панель для текущего режима. У Матрицы — чувствительность, группировка частот, скорость реакции; у Spectral Flow — амплитуда, ширина изгибов, объединение пиков, скорость реакции, затухание, количество полос, свечение. Настройка цвета общая для обоих режимов, меняется только цветовой тон исходных градиентов/свечения; их яркостная структура сохраняется.

Настройки изменяются немедленно, автоматически сохраняются в localStorage и применяются при повторном открытии сайта. Они могут удалиться при очистке ВСЕХ данных сайта/приложения. Отдельного экспорта, импорта и отображения FPS нет. Кнопка «Сбросить параметры режима» не затрагивает другой режим и выбранный общий цвет.

ГЕОМЕТРИЯ ВОЛНЫ: плавная интерполяция формы по кубическому полиному Эрмита с ограничением производных у экстремумов, с отрисовкой каждые 3 px. Это обеспечивает плавные вершины без искусственных перегибов и без уменьшения высоты пика. Формирование и знак локальных деформаций остались из v3.

КАЛИБРОВКА ШУМА: включите микрофон, оставьте источник постоянного фонового шума работать, выключите музыку, нажмите «Убрать фоновый шум» и сохраняйте тишину 3 секунды. Профиль сохраняется отдельно, его можно сбросить.

ОБРАТНАЯ СОВМЕСТИМОСТЬ: при исходных настройках Матрица сохраняет параметры обработки v9.2 и исходную зелёную палитру. Исходная версия v3 не изменена.
