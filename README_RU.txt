Matrix Spectrum + Spectral Flow v5 — Stable Studio

Установка: распаковать ZIP и заменить файлы в корне GitHub Pages. Обновить KioskHQ; при старой версии очистить кеш файлов (не обязательно данные сайта).

ЧТО ИСПРАВЛЕНО В ВОЛНЕ
В v4 был резкий переключатель главных FFT-пиков по полосам. В зависимости от выбранного максимума менялась и фаза волны, из-за чего форма скачкообразно менялась при речи и свисте.
В v5 дискретное отбрасывание пиков удалено. Применяются непрерывное сглаживание интенсивностей соседних полос, общая пространственно-непрерывная фаза, временное сглаживание всей кривой с учетом dt. Это должно значительно уменьшить скачки. Сохранена двусторонняя волна, 11 нитей, мягкое свечение, непрерывность линий на краях и PCHIP-интерполяция, введенная в v4.

НАСТРОЙКИ
Матрица: чувствительность, группировка и скорость реакции 0–300%. Нулевую скорость понимать буквально: текущий уровень зависает; для возобновления поднимите ее выше нуля или сбросьте режим.
Волна: амплитуда 0–400%, ширина 25–600%, группировка 0–300%, реакция 0–1000 мс, затухание 0–2000 мс, частотные полосы 8–64, свечение 0–300%. Для реакции/затухания 0 мс означает мгновенное изменение.
Панель шире (до 860px, 97% экрана), ползунки удобнее для касания и более точной настройки. Цвет по-прежнему общий для обоих режимов. Автосохранение в localStorage, совместимо с сохранениями Studio v4. Без FPS, экспорта и отдельных пресетов.

ПРОВЕРКА
Рекомендуется сначала сбросить параметры «Волн», проверить речь, свист, тишину, удар баса, а затем экспериментировать с ползунками. Обновление кода не означает, что реальная плавность уже подтверждена на Redmi Pad 2.

Матрица: вычислительные формулы, исходные настройки и изображение сохранены; изменены только доступные диапазоны настроек.
