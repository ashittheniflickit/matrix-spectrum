MATRIX SPECTRUM v9.2 + SPECTRAL FLOW v1

Два режима в одном приложении для GitHub Pages и KioskHQ.

РЕЖИМ 1 — МАТРИЦА
Исходная визуализация v9.2 без изменений в алгоритме, цветах, свечении и скорости.

РЕЖИМ 2 — SPECTRAL FLOW
11 непрерывных светящихся зелёных линий, уходящих за оба края экрана.
Линии реагируют на частоты 40–12000 Гц в реальном времени.
Нет истории, накопления кадров или симуляции жидкости.
При отсутствии сигнала линии постепенно выпрямляются.
Используются тот же микрофон и тот же сохранённый профиль шума.

УПРАВЛЕНИЕ
Нажми «Режим: Матрица» для переключения в Spectral Flow и обратно.
«Микрофон» включает реальный звук, «Демо» переключает синтетическую демонстрацию.
«Убрать фоновый шум»: выключи музыку, оставь компьютер/вентилятор
работать, нажми кнопку и помолчи примерно 3 секунды.
Профиль сохраняется локально и используется обоими режимами.
«Сброс шума» возвращает исходную чувствительность.

УСТАНОВКА
Распакуй архив, загрузите все 6 файлов в корень репозитория GitHub Pages.
После публикации обнови страницу KioskHQ; при необходимости очисти кеш.
Сохрани прежний ZIP v9.2 для отката.

ПРОИЗВОДИТЕЛЬНОСТЬ
Spectral Flow использует Canvas 2D, 36 частотных полос, 11 линий.
Спектр анализируется с периодом ~32 мс, геометрия обновляется через
requestAnimationFrame. Физической симуляции и WebGL нет.
Плавность на реальном Redmi Pad 2 требует проверки.

ОГРАНИЧЕНИЯ
Звуковой поток по-прежнему считывается микрофоном, не из Android.
Ноты и гармоники могут накладываться; это художественная визуализация.
Калибровка подавляет стационарный фон, но может скрывать тихую музыку.
