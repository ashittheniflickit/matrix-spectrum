MATRIX SPECTRUM v9.1 — минимальная финальная доработка v9

Установка (GitHub Pages):
1. Сохраните рабочий архив/папку v9 для отката.
2. Распакуйте архив v9.1. Загрузите ВСЕ файлы из распакованной папки в корень существующего репозитория GitHub Pages, заменяя одноимённые. Не помещайте саму папку в корень репозитория.
3. Дождитесь завершения публикации сайта.
4. При старой версии экрана очистите кеш KioskHQ в настройках Android и перезапустите страницу.
5. Для отката замените файлы в репозитории ранее сохранёнными файлами v9 (включая sw.js, если он был сохранён).

Основное:
- За основу взят оригинальный index.html v9, а не v10.
- Без изменений: палитра, яркость цифр, фон, свечение, скорость 64 мс, размер и число столбцов, шкала 40–12000 Гц, FFT 8192, пороги v9, затухание длительного звука (baseline*.50), способ отрисовки Canvas.
- Исправлено: при просадке кадров один FFT-снимок анализируется один раз, а не 2–3 раза.
- Устранён скачок коэффициентов басов около 209 Гц: плавное смешивание в диапазоне ~20–38% экрана, с сохранением точных коэффициентов v9 снаружи диапазона.
- Диагностика: в строке состояния микрофона указаны EC / NS / AGC из getSettings() (если доступны); полный объект выводится в консоль.
- Меняется версия сервис-воркера для обновления кеша; сетевой запрос при доступном интернете имеет приоритет.

Осознанно НЕ внесено:
- Фильтрбанк, новая система шумового пола, автонормализация громкости, новый Canvas-рендерер, два анализатора, калибровка, ослабление baseline*.50. Это экспериментальные изменения, которые могут изменить понравившуюся картинку v9.

Ограничения: проверка в Chromium/симуляции не заменяет тест на реальном микрофоне Redmi Pad 2 + KioskHQ. Если новый характер перехода около 209 Гц субъективно хуже, используйте сохранённый v9.
