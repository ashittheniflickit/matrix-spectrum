MATRIX SPECTRUM v9.2 — v9.1 + калибровка фонового шума

УСТАНОВКА:
1. Сохраните рабочую v9.1 на компьютере для отката.
2. Распакуйте архив. Загрузите ШЕСТЬ файлов из него в КОРЕНЬ вашего GitHub Pages репозитория, заменяя одноимённые файлы. Не переносите внешнюю папку целиком.
3. Дождитесь публикации. Если KioskHQ показывает старый сайт: Настройки Android → Приложения → KioskHQ → Память → Очистить кеш. Не очищайте данные приложения без необходимости.
4. Откат: замените эти же шесть файлов сохранёнными файлами v9.1.

КАК УБРАТЬ ШУМ КОМПЬЮТЕРА:
1. В комнате должна быть обычная фоновая обстановка: компьютер работает, музыка выключена, не разговаривайте.
2. На сайте включите микрофон и нажмите «◌ Убрать фоновый шум».
3. Подождите около 3 секунд, не включая музыку и не разговаривая. Сайт построит частотный профиль шума и сохранит его в localStorage.
4. Включите музыку. При активном профиле сигналы в пределах ~3 дБ от зафиксированного шума подавляются; выше ~12 дБ отображаются практически без изменений. Между ними плавный переход. Профиль применяется только к музыке с микрофона, не в деморежиме.
5. Кнопка «↺ Сброс шума» полностью отключает дополнительное подавление и возвращает исходное поведение v9.1 без изменения файлов. Перекалибровка перезаписывает предыдущий профиль.

НЕ ИЗМЕНЕНО:
- Цвет, яркость, нули, мягкое свечение и рендеринг оригинальной v9.1.
- Логарифмическая шкала 40–12000 Гц, FFT 8192, ширина столбцов, скорость PERIOD=64 мс.
- Все коэффициенты алгоритма v9.1 при отсутствии калибровки.
- Нет новых зависимостей и сетевых запросов.

ОГРАНИЧЕНИЯ:
- Система не умеет отделять музыку от шума, если они занимают одинаковые частоты и близки по громкости. Тихие фрагменты на фоне гула могут частично ослабнуть.
- При изменении шума (скорость вентилятора, расположение планшета, громкость компьютера) повторите калибровку.
- Браузер может блокировать localStorage в приватном режиме; в этом случае профиль работает до обновления страницы.
- Реальный микрофон Redmi Pad 2 / KioskHQ должен быть проверен на устройстве.
