MATRIX SPECTRUM v9.2 + SPECTRAL FLOW v2 — LIQUID RIBBONS

Один сайт для GitHub Pages / KioskHQ, два режима.

МАТРИЦА
Визуализация и обработка звука исходной v9.2 не менялись.

SPECTRAL FLOW v2
11 близко расположенных нитей, движущихся как одна светящаяся лента.
Нити непрерывно выходят за левый и правый края экрана.
18 частотных полос вместо 36; широкое сглаживание и мягкое объединение
соседних пиков. Амплитуда крупных изгибов примерно вдвое больше.
Одна общая волна без независимых фаз каждой нити; свечение общее.
В тишине лента становится ровной. История звука не сохраняется.

УПРАВЛЕНИЕ
Кнопка «Режим» переключает Матрицу / Spectral Flow.
Микрофон и калибровка фонового шума общие для обоих режимов.
Для калибровки включите микрофон, выключите музыку, оставьте
компьютер включённым и нажмите «Убрать фоновый шум» на 3 секунды.
«Сброс шума» удаляет профиль. Демо позволяет посмотреть движение без музыки.

УСТАНОВКА
Загрузите все шесть файлов из ZIP в корень репозитория GitHub Pages.
Дождитесь публикации и обновите KioskHQ, при необходимости очистите кеш.
Сохраните предыдущую версию для отката.

ОГРАНИЧЕНИЯ
Визуализатор получает звук через микрофон планшета, не напрямую из Android.
Отдельные гармоники могут вызывать несколько волн — это не детектор нот.
Фактическую плавность на Redmi Pad 2 нужно проверить на устройстве.
